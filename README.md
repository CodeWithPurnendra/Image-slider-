# 🎞️ Image Slider | HTML, CSS & JavaScript

A clean, responsive, and lightweight **Image Slider (Carousel)** built using **vanilla HTML, CSS, and JavaScript**.  
This project demonstrates DOM manipulation, smooth transitions, and interactive UI behavior without using any external libraries or frameworks.

---

## 🚀 Features

- 🖼️ Smooth image sliding animation  
- ⏭️ Next & Previous navigation buttons  
- 🔄 Automatic sliding (optional)  
- 📱 Fully responsive design  
- ⚡ Lightweight & fast (no libraries)  
- 🎯 Beginner-friendly JavaScript logic  

---

## 🛠️ Built With

- **HTML5** — Structure  
- **CSS3** — Styling & animations  
- **JavaScript (ES6)** — Slider logic & interactivity  

---

## ⚙️ How It Works

1. Images are placed inside a container  
2. JavaScript tracks the **current slide index**  
3. CSS `transform: translateX()` is used for smooth sliding  
4. Buttons trigger slide changes using event listeners  

---
